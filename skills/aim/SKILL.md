# aim —— 人物形象仓

**一句话**：`aim` 把「这个人是谁」定成一份 JSON（契约），
再由脚本把它渲染成**这个人的**素材与片子。

```
确认流程（音色定标 → 形象确认 → 人格确认 → 品牌片定稿）
   │
   ▼
models/<slug>/model.json          ← 这个人（唯一契约）
   │
   ▼
下游读它 → 渲染 → 成片
```

**缝是一个文件**：下游只**读** `model.json`，不 import aim 的任何模块。
JSON 是**索引与参数**，不是这个人本身——人 = 规则（specs）× 契约（model.json）× 产物（PNG/MP4/WAV）。

---

## 怎么用

**入口**：{{AIM_HOME}}/aim —— **在仓根跑**（`./aim`）。

```bash
{{AIM_HOME}}/aim --help              # 列全部命令
{{AIM_HOME}}/aim character           # 列这一组的动作
{{AIM_HOME}}/aim character badge --help
```

| 阶段 | 命令 | 干什么 |
| --- | --- | --- |
| 体检 | `aim doctor` | 这个人的契约与素材齐不齐（**只报告，不改**） |
| 契约 | `aim model build` | 把确认结论归一化成 `model.json`（校验通过才写） |
| 字体 | `aim font install` | 装内置字体子集（跨机版式一致靠它） |
| 形象 | `aim character generate` | 生成主形象与 6 姿态表（**消耗生成额度**） |
| 形象 | `aim character glasses` | 戴眼镜（**没声明眼镜就整体跳过**） |
| 形象 | `aim character badge` / `clear-badge` / `white` | 盖铭牌 / 抹铭牌 / 铺白底 |
| 品牌片 | `aim brand poses` / `backgrounds` / `render` / `fix-plates` / `audio` | 姿态、背景、片头片尾、底板文字、成品音轨 |
| 音色 | `aim voice measure` / `voice check` | 量测参照录音 / 查多音字读音 |

**参数原样转交**给脚本，**退出码原样传回**——
每个命令的完整参数看 `--help`。

### 指一个人

脚本在 import 时就读模型，所以**得先指一份**：

```bash
export AIM_MODEL={{AIM_MODEL}}
```

**不猜用哪个人**：仓里有好几个人时报错列出候选，**绝不猜**
（猜错就是拿别人的事实去生成这个人的素材与片子）。

## 铁律

1. **跨仓零 import**——下游只**读** `model.json`。
2. **入库的是事实，不入库的是产物与素材**——素材只在本地，入库的是「它在哪」。
3. **只做框架，不做内容**——规范写成可替换的规则模板。
4. **身份不在框架里**——人格、音色、形象、站名、配色**一律从 `model.json` 读**。
   换人只改模型，不改代码。
5. **不拿默认值糊过去**——这个人不戴眼镜就**整体跳过**加眼镜流程；
   身份没写就**空着**，不编一句占位符。
   糊过去了，下游就分不清「定错了」和「还没定」。
6. **可空的字段就让它空着**——空 = 「还没定」，不是错误。
7. **契约坏了才是硬错误**——`model.json` 读不了 / 形状不认识 → **报错退出**，不降级。
   素材文件不在 → **降级**，`doctor` 单独报。
8. **文字一律用真实字体渲染**——模型生成的中英文会乱码。
9. **相对路径的基准是 `model.json` 所在目录**——下游不需要知道仓根在哪。
10. **形状变了就涨 `schema`**——读不懂新形状时**报错退出**，不静默忽略。
    **涨版本号之前先想清楚：还有谁在读这份契约。**
    缝是文件，**每一端各有一份读取器**——上游涨了，下游那份不跟着涨，
    下游就会报错退出（那是对的），但**得有人去改那一端**。
11. **不猜用哪个人**。
12. **验收按模块拆开**——谁改了什么，只有谁的套件会红。

## 动手之前

- **先读** `{{AIM_HOME}}/AGENTS.md`（中央入口）、`{{AIM_HOME}}/README.md`（总览）。
- **要动手的细节**看 `{{AIM_HOME}}/docs/使用教程.md`（从 clone 到出片的操作手册）。
- **规范**在 `{{AIM_HOME}}/specs/`：平台契约 / 形象 / 音色 / 品牌片 / 人格。
- **改之前先跑**：`cd {{AIM_HOME}} && python3 -m pytest tests/ -q`
  （本仓小，模块之间共用同一份 `model.json`，拆开跑没意义）。
- **禁碰**：`models/*/assets/`（素材，不入库）、`models/*/_staging/`（中间产物）。
